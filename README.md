# Rabiscando a Palavra · materiais de estudo

Página fixa dos materiais de estudo em PDF da série. É o destino do botão "Abrir o material" da automação "comenta LOUSA" no Instagram.

- Página: https://reoliveira87.github.io/rabiscando-a-palavra/
- PDFs: `licao-NN/` (um por lição)

## Como incluir uma lição nova
1. Crie a pasta `licao-NN/` e ponha o PDF dentro.
2. Em `index.html`, copie o bloco `<article class="licao">`, troque número, título, texto bíblico, data e caminho do PDF, e deixe a lição mais nova em cima.
3. `git add -A && git commit -m "Lição NN" && git push`. O GitHub Pages atualiza em cerca de 1 minuto.

O endereço da página não muda, então o botão da automação não precisa ser trocado.
